32-bit ALU Design using Verilog HDL

Designed and implemented a 32-bit Arithmetic Logic Unit (ALU) using Verilog HDL capable of performing arithmetic and logical operations such as addition, subtraction, AND, OR, XOR, and shift operations.

Verified functionality using a self-checking testbench and analyzed simulation waveforms for different ALU operations.

Tools Used
Verilog HDL
Xilinx Vivado 

Features
32-bit data path
Multiple arithmetic and logical operations
Testbench verification
RTL schematic and waveform analysis
